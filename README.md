# Geldabenteuer

[🎲 Spiel starten](https://adrianzuercher0004-blip.github.io/geldabenteuer/)

Interaktives Leiterlispiel für 1–4 Kinder ab etwa 7 Jahren: mit Geldfragen, Aktionsfeldern, Sparzielen und einem Lernvideo mit Raiffi.

## Auf dem Handy speichern

- iPhone: Spiel in Safari öffnen → Teilen → Zum Home-Bildschirm.
- Android: Spiel in Chrome öffnen → Menü → App installieren.
- Nach dem ersten vollständigen Laden zeigt „Aufs Handy“ an, ob Spiel und Lernvideo offline bereit sind.

## Aktualisieren

Die Spieldateien liegen in `Geldabenteuer-GitHub.zip`. Änderungen an diesem Paket werden automatisch über GitHub Pages veröffentlicht.

Inoffizieller Spielentwurf im Raiffeisen-Stil; kein offizielles Angebot.
